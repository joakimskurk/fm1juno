# Deterministic vectors

This directory will hold compact, versioned event/control vectors. Large WAV captures do not belong here.

First vectors cover:

- allocator/retrigger behavior;
- ENV/LFO/Portamento integer state;
- physical 12-bit DAC boundary;
- control-scheduler order and note-event restart;
- 8253 Mode-3 even/odd and pending-vs-reset behavior.
